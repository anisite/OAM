# securite OIM

Ce répertoire sert d'archives des demandes de sécurité pour le système OIM

## Comptes applicatif OIM

Un compte applicatif créé par environnement (un, ac, it et pr)

Accès aux services externes
- Groupe servant à l'accès aux services communs (gt_700_CAC_ServicesCommuns)
- Permet d'accéder aux ressources des FH  (gr_700_FH_ServiceCon)
- Permet d'accéder aux services du noyau intersystème GDI (gr_700_GDI_ServiceCon)
